1 Introduction

Customer Auto Reply ("the Application", "we", "our") is a private tool operated by the account owner that automates responses to Instagram direct messages. It integrates with Meta's official Instagram Graph API and Webhooks to receive and send messages on behalf of the connected Professional Instagram account.

This Privacy Policy explains what information the Application processes during its normal operation, how that information is used, and the rights available to individuals whose information is involved.

The Application is not a consumer-facing product. It is operated privately by the account owner to manage their own Instagram communications.

2 Information We Collect

The Application only processes information that is necessary for its functionality. This may include:

  • Instagram User ID — the unique identifier provided by Meta for the sending Instagram account.
  • Instagram Username — when provided by the Meta API alongside a message event.
  • Message Content — the text of incoming direct messages delivered by Meta's Webhooks.
  • Message ID (mid) — a unique identifier for each message event used to prevent duplicate processing.
  • Event Timestamps — the time at which a message or conversation event occurred.
  • Approved-User Status — a record of which Instagram User IDs are authorised to trigger automated responses.
  • Conversation State — a minimal record to track whether an automated reply has been sent within a session.
  • Server Log Data — standard technical information (e.g. request method, HTTP status code, response time) required to operate and diagnose the service.

The Application does not collect passwords, payment information, location data, device identifiers, or any information unrelated to its messaging automation functionality.

3 How We Use Information

Information processed by the Application is used solely to:

  • Receive and parse incoming Instagram direct message webhook events delivered by Meta.
  • Determine whether the sending Instagram user is in the configured approved-user list.
  • Send automated reply messages to approved users via the Instagram Graph API.
  • Prevent duplicate automated responses for the same message event.
  • Maintain basic conversation state to avoid unnecessary repeated messages.
  • Support operational logging and error diagnostics for the service owner.

The Application does not use personal information for advertising, profiling, marketing, or any purpose beyond the direct messaging automation described above.

4 Instagram / Meta Platform Data

The Application connects to Meta's Instagram Graph API using an access token issued to the account owner's Instagram Professional Account. This connection is subject to Meta's own privacy policies and terms of service.

Webhook events are delivered by Meta's servers to the Application's endpoint. The Application does not independently scrape, monitor, or collect Instagram data beyond what is delivered via official API channels.

API credentials (such as access tokens and verification tokens) are stored securely on the server and are never included in frontend code, HTML pages, API responses, or public files.

For more information about how Meta handles your data, please review Meta's Privacy Policy and the Meta Platform Terms.

5 Automated Messaging

The Application sends automated Instagram direct messages in response to incoming messages from approved Instagram users. These automated replies are pre-configured by the account owner and are sent using the official Instagram Graph API.

Automated responses are only triggered when:

  • An incoming direct message event is received from Meta's Webhooks.
  • The sending Instagram user is present in the approved-user list.
  • The automation has not already been triggered for that conversation session.

The Application does not send unsolicited messages. It only responds to direct messages that are first initiated by the other party.

6 Approved Users

The Application maintains a list of approved Instagram User IDs. Automated replies are sent only when a message is received from an Instagram account whose User ID is on this list.

Instagram accounts that are not on the approved-user list will not receive any automated response. Their messages may still be delivered to Meta's Webhooks but the Application discards the event without taking any action.

The approved-user list is managed exclusively by the account owner. Inclusion on this list is based on the account owner's operational decisions.

7 Data Storage and Retention

In the current implementation, the Application maintains data in server memory during operation. This includes the approved-user list, conversation state, and a record of recently processed message IDs used to prevent duplicate events.

This in-memory data does not persist between server restarts unless a persistent database (such as PostgreSQL) has been configured. When the server restarts, transient session data is cleared.

Standard server log data (HTTP request logs) may be retained for a limited period as required to diagnose errors and maintain the reliability of the service. Log entries do not contain message content or full access tokens.

Data is retained only for as long as it is necessary for the Application's operational purpose. When data is no longer required, it is deleted or discarded.

8 Data Security

The Application implements reasonable technical measures to protect processed information, including:

  • API credentials and access tokens are stored only in server-side environment variables and are never included in client-facing code or responses.
  • HTTPS is used for all public-facing endpoints via a secure tunnel.
  • Webhook verification tokens are compared securely before any webhook event is processed.
  • Sensitive values are automatically redacted from application logs.

No security system is perfect. The account owner is responsible for maintaining the security of the server environment, access credentials, and any connected services.

9 Data Sharing

The Application does not sell, rent, or commercially share personal information with any third party.

Information processed by the Application is used exclusively by the account owner for the purposes described in this Privacy Policy.

The Application interacts with Meta's Instagram Graph API as a technical integration, which requires sending message content and recipient identifiers to Meta's servers in order to deliver automated replies. This data transfer is governed by Meta's terms of service and privacy policies.

10 Third-Party Services

The Application integrates with the following third-party service:

  • Meta / Instagram Graph API — Used to receive incoming direct message events and to send automated replies. Meta's use of data is governed by the Meta Privacy Policy and Meta Platform Terms.

The Application does not embed third-party tracking scripts, analytics services, or advertising networks. This Privacy Policy page contains no external JavaScript.

To submit a data deletion request:

  • The account owner will review the request and remove any data associated with you from the Application's records.
